# Owner editing guide

The website is designed so routine content can be edited through Pages CMS rather than by editing code.

## What the owner can edit

- Phone number and address
- Office hours
- Homepage headline and introduction
- Optional homepage announcement
- Services and their display order
- Provider biographies and photographs
- Downloadable PDF forms
- Page title and description for the homepage

## Safe editing rules

1. Upload images through the Website images library. Use clear images at least 1600 pixels wide for large office photographs.
2. Write useful alternative text that describes the image's purpose. Do not start with “image of.”
3. Keep the homepage headline under 110 characters.
4. Turn off “Show service” or “Show profile” rather than deleting content that may be needed later.
5. Replace a PDF using the same form entry so the website link updates safely.
6. Preview the Cloudflare deployment after saving and before sharing changes publicly.

Pages CMS writes edits to GitHub. Cloudflare Pages then rebuilds the static site. No database is involved.
